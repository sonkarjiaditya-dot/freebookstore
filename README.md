# FreeBookStore

A modern, dark-themed e-book discovery and reading site built with React, Vite, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Structure

- `src/App.jsx` — the entire app (header, hero, search, book cards, category pages, book details, reading page, about/contact/login) using internal state-based routing.
- `src/index.css` — Tailwind entry point.

All book cover art and the hero illustration are original SVG/CSS graphics — no third-party or copyrighted imagery is used.
